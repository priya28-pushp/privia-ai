# Privia AI 🏠

### Intelligent Apartment Discovery & Decision-Support Dashboard

Privia AI is a web-based apartment discovery dashboard designed to help users
find and compare apartments based on their personal preferences.

## ✨ Features

- Apartment discovery dashboard
- Budget-based apartment matching
- Multi-factor Match Score
- Location preference matching
- Bedroom preference matching
- Furnished/unfurnished preference
- Parking preference
- Pet-friendly preference
- Natural-language apartment search
- Apartment details
- Side-by-side apartment comparison
- Budget intelligence
- Responsive and modern UI
- Login and signup interface

## 🧠 Match Intelligence

Privia AI calculates an apartment Match Score using multiple factors:

- Budget
- Location
- Number of bedrooms
- Furnishing
- Parking
- Pet friendliness

This allows users to compare apartments based on their individual requirements.
